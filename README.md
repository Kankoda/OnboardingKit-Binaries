# OnboardingKit Binaries

This repository is used to host release artifacts and dSYMs for the [OnboardingKit SDK][Repository]. Each tag in this repo matches an SDK version in the [main repository][Repository].


## Website

The [OnboardingKit website][Website] has information about the SDK, a blog with the latest news, pricing info, etc.


## Repository

The [OnboardingKit repository][Repository] contains the SDK, as well as a demo app that shows how to use it.


## Documentation

The [OnboardingKit documentation][Documentation] has a getting-started guide, articles, code samples, etc.


## Binaries

The [OnboardingKit binaries][Binaries] contains the SDK and its releases.
